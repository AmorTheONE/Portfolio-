## 🛡️ Overview

Modern, responsive, and accessible professional portfolio built for **Amor Dewan**, showcasing Security Operations (SOC), digital forensics investigations, cloud architecture (Azure/AWS), and hardened full-stack web applications.

Designed with an obsidian cyber theme, accessible WCAG 2.2 AA standards, interactive terminal emulation, and seamless connection to the live Django REST Framework API.

## 🛠️ Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AmorTheONE/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Create a production build:**
   ```bash
   npm run build
   npm run start
   ```
